# Player

Движок интерактивных объяснений в вебе. Снаружи похоже на видео — озвучка, таймлайн,
анимации — но внутри это DOM, поэтому зритель может взаимодействовать с содержимым.
Автор ставит на таймлайне **гейты**: точки, где плеер останавливается и открывает
взаимодействие. Плюс редактор в духе Canva и импорт `pptx`.

> Это движок в разработке, а не задеплоенный продукт. Прод-домена нет, только локальный dev-сервер.

## Структура
| Пакет | Что это |
|---|---|
| `packages/core` | ядро |
| `packages/player` | плеер |
| `packages/editor` | редактор (161 файл) |
| `apps/playground` | стенд |
| `e2e` | end-to-end сценарии (78 файлов) |
| `spikes/` | 14 исследовательских стендов |

## Стек
pnpm-монорепо, TypeScript 7, Vite 8, React 19, Vitest 4, Playwright 1.62,
`@scena/react-guides`, `react-moveable`, `pptx-viewer-core`, `animejs`, `pixelmatch`.

База: схема v11, 10 миграций.

## Тесты
1 459 юнит-тестов в 48 файлах, 313 e2e зелёных, 90 скриншотных эталонов.
Всего 344 тестовых файла.

CI (`check.yml`): типы 6 проектов → юниты → сборка → e2e.

## Инженерная документация
- 26+ ADR — по файлу на каждое архитектурное решение, с датами и отменёнными решениями
- design-system документация: два набора токенов, десять ролей темы
- `debt.md` — открытые решения владельца, `known-bugs.md`, журнал на каждую сессию
- `research/` — разборы с замерами

## Как запустить
```bash
pnpm install
pnpm dev            # playground
pnpm test           # юнит-тесты
pnpm test:e2e       # Playwright
```

Соло, 270 коммитов за 22 дня (с 27 июля 2026), ~198 000 строк — самый большой проект.
