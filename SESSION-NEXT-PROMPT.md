## Задача 1. Морфинг между слайдами

Главное этой сессии. Фикстура `morph.json` сделана специально: три слайда,
элемент едет и растёт, один приходит, один уходит.

**Что считать:** для каждого элемента сравнить состояния соседних слайдов.
Есть в обоих — интерполируем. Только в предыдущем — уходит. Только
в следующем — приходит.

**Чем анимировать:** FLIP через `transform` и `opacity`. Движок — **anime.js**,
он уже в проекте. GSAP брать нельзя, лицензия проверена дважды.

**Три вещи, которые легко сделать неправильно:**

- **`width`/`height` анимируются через `scaleX`/`scaleY`**, а не напрямую.
  Иначе уходим с композитора и роняем кадры — инвариант №8. Модель хранит
  геометрию, композитор двигает трансформацию.
- **«Нет в states» и `visible: false` — разные переходы.** Отсутствие: элемент
  приходит, предыдущей позиции нет, морфинга нет. `visible: false → true`:
  проявляется на своём месте и **может ехать**, позиция известна. Поэтому
  скрытый элемент рендерится как `visibility: hidden`, а не `display: none` —
  бокс раскладки обязан сохраниться, иначе FLIP нечего измерять.
- **Несовпавшие элементы проявляются с задержкой**, пока совпавшие едут.
  Посмотри, как это сделано в reveal.js auto-animate.

**`transition: 'cut'`** — намеренный разрыв, применяется мгновенно.

**Проверка:** два слайда с общим элементом дают плавный переход, а не мигание.
Покадрово, а не скачком: при большом скачке движок форсирует рендер, и сломанная
реализация выглядит исправной. На этом уже обжигались — ADR-009.

## Задача 2. Гейт с разбором на месте

Фикстура `inline-explain.json` готова.

`onWrong: 'inline-explain'` — показать разбор **слоем поверх сцены**, не покидая
сегмент. Базовый таймлайн на паузе, потом продолжить ту же дорожку.
`inline-hint` — то же самое, но короче.

**Порядок при совпадении времени — решение [Р] в `product.md` §3.** Если гейт
и смена слайда попали на одну точку: гейт встаёт в свою секунду, **незавершённый
переход мгновенно доводится до конечного состояния**, и только потом открывается
взаимодействие. Зритель не отвечает поверх едущих элементов. Буквальное
«доиграть переход» нарушило бы инвариант №4 на 300–900 мс при измеренном
перелёте 18.57 мс — врезка с обоснованием есть в `product.md`.

Редактор при этом предупреждает автора: гейт внутри перехода — почти всегда
ошибка расстановки.

**Переменные зрителя живут на всё объяснение** и переживают переходы между
сегментами. Это уже работает в плеере (`#answers`), проверь, что не сломал.

## Задача 3. Часы за интерфейсом

Долг из `planning.md` §13.1, расхождение с `product.md` §3 [Р].

Сейчас `AudioClock` — конкретный класс, `Player` создаёт его напрямую,
поле `#clock` типизировано классом. Требование: **часы — интерфейс**, даже
если реализация одна.

```
Clock { time(), play(), pause(), duration(), onEnd() }
```

**Почему сейчас, а не потом.** `#clock` упоминается в `player.ts` примерно
в двадцати местах, и все они про `position`, `duration`, `start`, `freezeAt`,
`resumeFromFreeze` — ровно про то, что должно быть интерфейсом. Пока реализация
одна, извлечение механическое. Когда появится вторая (`timer` для немого видео,
`manual` для тренажёра), это станет переписыванием под давлением.

**Границы:** введи тип, оставь `AudioClock` единственной реализацией, `Player`
принимает часы, а не конструирует их. Поле режима в схеме — **не сейчас**,
это бамп версии ради поля, которое пока некому читать.

## Задача 4. Доделать e2e и снять эталоны

- Почини оставшиеся спеки. Метод: запусти один файл, прочитай настоящую ошибку,
  не угадывай. Часть падений — устаревшие идентификаторы, часть — тесты,
  у которых исчез предмет вместе с кью (их удалить, а не чинить).

- **Эталоны с морфингом покажи владельцу ДО того, как они станут эталонами.**
  Это его прямое требование, и оно разумное: переснятый эталон перестаёт быть
  страховкой ровно в той сессии, где она нужнее всего.

## Чего не делать

- **Доску нодов.** Её делает владелец после Сессии 8.
- **Загрузку своего аудио** и посегментную запись — это следующий большой блок,
  не этот.
- **`wavesurfer.js`.** Измерен, годен, вердикт записан в `planning.md` §10.1.
  Менять, когда появится правка дорожки, не раньше.
- **`{ kind: 'step' }` в `TimeRef`.** Нужен только для режимов `timer`
  и `manual`, которых пока нет. Сейчас это незапрошенная гибкость.
- **Префикс переменных `${segmentId}.${gateId}`** (долг §13.2) — если не
  останется времени, отдай в Сессию 8. Пока блоки не вставляются из других
  проектов, разница теоретическая.

## Грабли, на которые уже наступили — не наступай повторно

**`checkVisibility()` по умолчанию не видит `visibility: hidden`.** Он смотрит
только на `display` и `content-visibility`. Нужны флаги
`{ visibilityProperty: true, opacityProperty: true }`. Без них тест зелёный
на сломанном коде и красный на верном.

**Три подпанели не делят колонку высотой.** Замерено дважды: список элементов
получал высоту 0 при семи отрисованных строках; список частей — 0 при
содержимом 70 px, и клик по части попадал в кнопку «Удалить часть». Колонка
прокручивается целиком, у списков свой потолок.

**Обратные кавычки в `styles.ts` обрывают шаблонную строку.** Файл — это один
большой template literal. CSS-комментарий с бэктиками ломает сборку.

**`dragStart` нельзя откладывать на кадр.** Если понадобится связывать selecto
и moveable: вызов внутри `requestAnimationFrame` получает устаревшее событие,
и ресайз молча превращается в перетаскивание.

**Самописную манипуляцию элементами так и не заменили на moveable.** Спайк
доказал, что она работает (`pnpm spike:editor-stack`, числа
в `research/editor-stack.md`), но подключения в редактор нет. Если возьмёшься —
это отдельный крупный кусок, не смешивай с морфингом.

## Законы, которые легко нарушить именно здесь

- **Инвариант №1:** аудио — единственный источник времени. Никакого своего
  таймера в морфинге.
- **Инвариант №2:** сцена ведомая. Ей выставляют время, она не играет сама.
- **Инвариант №5:** один рендер на плеер и редактор.
- **Инвариант №8:** только `transform`, `opacity`, `filter`.
- **Позиционирование не просачивается в код:** сегмент, зритель, объяснение.
  В интерфейсе — «части».
- **`pnpm check` после каждого изменения**, и смотри числа, а не код возврата.
