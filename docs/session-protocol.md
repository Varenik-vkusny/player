# Протокол сессий: кто что делает и что проверяется всегда

Заведён 17.08.2026, Сессия 44, по решению владельца сменить порядок
работы. **Раньше** каждая сессия была новым чатом, а принимал работу
владелец. **Теперь** сессию ведёт агент, а принимаю её я — с теми же
правами и той же строгостью, с какой принимал владелец.

Владелец остаётся владельцем: облик, поведение, развилки продукта,
переоткрытие решений **[Р]** — по-прежнему только его слово.

---

## 1. Кто есть кто

| роль | кто | что делает |
|---|---|---|
| **Владелец** | человек | решает, что продукт делает; принимает облик; отвечает на развилки |
| **Приёмщик** | я, ведущий чат | ставлю задание сессии, принимаю работу СВОИМИ руками, коммичу, мержу |
| **Сессия** | агент на Opus 5 | ведёт одну сессию целиком: планирует, дробит, дожимает, пишет промпт следующей |
| **Исполнитель** | агент на Sonnet | делает одну задачу по готовой спецификации, доказывает сломом |

Сессия-агент **имеет те же привилегии, что новый чат**: читает `CLAUDE.md`
и документацию, планирует, заводит своих исполнителей, гоняет тесты,
открывает браузер. Разница ровно одна: **работу у неё принимает не
владелец, а я.**

---

## 2. Что сессия-агент получает на вход

1. Промпт сессии — по правилам «Промпт следующей сессии» из `CLAUDE.md`.
2. План работ из `docs/plans/`, если он есть.
3. Прямое указание читать `CLAUDE.md` первым делом.

## 3. Что сессия-агент обязан вернуть

- **Числа из прогона**, снятые с самих команд, а не через конвейер;
- **что срезано вслух** — поимённо, с причиной. Тихое сокращение
  выглядит в отчёте как выполненная работа: не врёт ни в одном
  предложении и обманывает целиком;
- **доказательства сломом** по каждому несущему тесту: вывод красного
  и вывод зелёного;
- **журнал находок** — файл, пополняемый в момент находки;
- **промпт следующей сессии**.

## 4. Что сессии-агенту ЗАПРЕЩЕНО

- **Изменяющие git-команды**: `add`, `commit`, `stash`, `checkout`,
  `restore`, `clean`, `worktree`, `merge`. Коммитит тот, кто проверил.
  Читающие (`status`, `diff`, `log`) — разрешены и нужны.
- **Менять `docs/design/*.md`, `docs/product.md`** и решения **[Р]**.
  Стало тесно — остановиться и спросить меня, я спрошу владельца.
- **Трогать эталонные фикстуры** в `fixtures/projects/` ради зелени.
- **Перезаписывать скриншотные эталоны не глядя.**
- **Нарушать инварианты.** Требует нарушить — остановиться и спросить.
- **Поднимать допуски** жестовых тестов, не найдя корня.
- **Заводить зависимость** без ADR и проверки лицензии по первоисточнику.

## 5. Операционные правила: два исполнителя в одном дереве

Куплено 17.08.2026 — чужой `git add -A` втянул посторонний журнал в свой
коммит, а чужие вкладки редактора держали замок и сделали редактор
доступным только для чтения.

- **Полный прогон — только один за раз.** Два `pnpm check` одновременно
  дают ЛОЖНОЕ КРАСНОЕ: оба поднимают дев-сервер на 5179 и оба пишут
  в один `player.js`, второй переписывает файл, пока первый его сверяет
  побайтово. В Сессии 15 это дало 35 прошедших из 210 при исправном коде.
- **Playwright гоняет только один агент.** Порт стенда 5179,
  `strictPort: true`, `reuseExistingServer` берёт всё, что отвечает.
- **Параллельные исполнители не пересекаются по каталогам.** Иначе
  платишь за чтение дважды и получаешь `TS2741` вместо теста.
- **Дев-сервер агент гасит за собой.** За Сессию 15 оставленный сервер
  трижды ломал следующий прогон.
- **Оборванный прогон выглядит как красный:** падение с временем `(0 ms)`
  и прочерки у соседей — до проверок дело не дошло.

## 6. ⬛ ЧЕК-ЛИСТ ПРИЁМКИ — выполняется ПОСЛЕ КАЖДОЙ СЕССИИ

**Отчёт агента фактом не считается.** Отчёт отвечает на вопрос «сделал ли
я, что просили», а не «то ли просили». В Сессии 4 приёмка нашла дефект
в четырёх задачах из пяти, и **ни один не был ошибкой исполнения**:
трижды не хватало задания, один раз задание было прямо неверным.

Каждый пункт я делаю **своими руками**.

### 6.1 Прогон

- [ ] `pnpm typecheck` — код возврата снят с самой команды
- [ ] `pnpm test:unit` — числа файлов и тестов записаны
- [ ] `pnpm build:player` — размер бандла записан
- [ ] `pnpm exec playwright test --shard=1/2` и `--shard=2/2`
- [ ] **Ни одно число не взято из доклада агента**

### 6.2 Диф

- [ ] `git diff --stat` прочитан целиком
- [ ] `git status --short` — нет чужого и незапланированного
- [ ] `fixtures/projects/` не тронуты (`git diff --name-only fixtures/`)
- [ ] `docs/design/*` и `docs/product.md` не тронуты без слова владельца
- [ ] `styles/*.ts`: обратных кавычек внутри шаблонных строк нет (все части)
- [ ] схема тронута? → бамп версии + миграция + фикстура + тест, все четыре

### 6.3 Инварианты

- [ ] нового хронометра не завелось (№1): ни `setInterval`, ни счётчика кадров, двигающего сцену
- [ ] второй реализации отрисовки не появилось (№5)
- [ ] направление `editor → player → core` цело (№6), и тест инвариантов **не правился ради зелени**
- [ ] анимируются только `transform`, `opacity`, `filter` (№8)

### 6.4 Тесты — не декорации

- [ ] по каждому новому несущему тесту спрошено: **что должно сломаться,
      чтобы он покраснел**
- [ ] хотя бы один слом воспроизведён **моими руками**, красное увидено
- [ ] грепом проверено, что слом убран из кода
- [ ] у каждой зелени есть объяснение, почему она зелёная. Три причины
      ложной зелени, проверять в этом порядке: **код не исполняется**;
      тест верен при ЛЮБОЙ реализации (тождество); проверяется вызов
      обработчика вместо видимого поведения

### 6.5 Глаза

- [ ] собранное приложение открыто в браузере, путь пройден руками
- [ ] консоль чиста
- [ ] каждый изменившийся скриншотный эталон **просмотрен глазами** до принятия
- [ ] проверено то, что тест поймать не может: **видно ли**, влезло ли,
      достижимо ли. Мерить `clientHeight` против `scrollHeight`, а не
      «нажимается ли»: Playwright сам прокручивает вложенный контейнер
      и честно нажмёт кнопку внутри 24-пиксельной щели

### 6.6 Честность отчёта

- [ ] названо вслух, что срезано, и с причиной
- [ ] половина закрытого не выдана за целое
- [ ] в промпте следующей сессии числа **из прогона**, а не из памяти
- [ ] в промпте нет утверждений о будущем, выданных за настоящее
      («ветка влита» до мержа) — такое проверяется командой, а не верой
- [ ] долги дописаны в `docs/debt.md`

### 6.7 И только теперь

- [ ] коммит **явным списком путей** (не `git add -A`)
- [ ] отчёт владельцу: **что теперь может автор**, первой строкой
