# План: масштаб дорожки и управление стыком

> **Исполнителю:** задачи идут по порядку, каждая кончается прогоном
> и коммитом. Шаги помечены `- [ ]`.

**Цель.** Автор может увеличить дорожку ступенями ×1…×16, попасть по стыку
перехода и потянуть его продолжительность прямо во времени.

**Подход.** Проценты от `durationSeconds` заменяются полотном шириной
`laneWidth × zoom` внутри контейнера с прокруткой. Модельная сторона
перехода уже существует и НЕ трогается.

**Спецификация:** [`docs/design/track-zoom.md`](../design/track-zoom.md).

## Общие ограничения

- **Высота зоны дорожки не меняется ни на пиксель.** Кнопки масштаба
  встают в существующую строку `.ed-transport`. Причина — `styles.ts:514–604`
  и `:1064–1080`: высота поднимается до `.ed-stage-host` и меняет масштаб
  сцены; дробная высота ломает это тихо.
- **`packages/editor/src/styles.ts` — одна шаблонная строка.** Обратная
  кавычка даже в комментарии обрывает весь файл. Наступали трижды.
- **Схема не трогается.** Версия остаётся v9.
- **`fixtures/projects/` не трогать.** Каждая фикстура лежит на своей
  версии схемы и проверяет миграцию.
- **`pnpm check` — только контроллер.** Исполнитель гоняет точечно:
  `pnpm exec vitest run -t "…"`, `pnpm exec playwright test -g "…"`.
- **Изменяющие git-команды запрещены.** Коммитит тот, кто проверил.
- Дев-сервер за собой гасить. Порт стенда 5179.
