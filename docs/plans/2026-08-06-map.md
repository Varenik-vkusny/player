# План: карта ветвлений

> **Исполнителю:** задачи идут по порядку, каждая кончается прогоном
> и коммитом. Шаги помечены `- [ ]`.

**Цель.** Автор видит объяснение доской: узел — часть, ребро — правило
перехода. С доски он заводит ветку, даёт ей имя и описание, правит
правила выхода и заходит внутрь.

**Подход.** Доска — **вычисленный вид**: раскладка считается чистой
функцией из графа, позиций в схеме нет. Рёбра — один `<svg>` на всю
доску, узлы — обычный DOM поверх (снято с натуры у Twine).

**Спецификация:** [`docs/design/map.md`](../design/map.md).
**Решение:** [ADR-027](../adr/ADR-027-map-rendering.md).

## Общие ограничения

- **Схема не трогается. Версия остаётся v9.** Координат узлов
  не появляется — это решение ADR-027, а не упущение.
- **Все части читать через `allSegments(project)`**
  (`packages/player/src/preview.ts:109`). Второго обхода
  `project.segments` не заводить: дисциплина `segmentOf` дважды окупилась
  и охраняется тестом инвариантов.
- **Направление зависимостей `editor → player → core`.** Обратных
  импортов нет.
- **`packages/editor/src/styles.ts` — одна шаблонная строка.** Обратная
  кавычка даже в комментарии обрывает весь файл.
- **Слов «урок», «раздел», «ученик» не заводить.** Часть, зритель,
  объяснение.
- **`fixtures/projects/` не трогать.**
- **`pnpm check` — только контроллер.** Точечно:
  `pnpm exec vitest run -t "…"`, `pnpm exec playwright test -g "…"`.
- **Изменяющие git-команды запрещены.**
- Дев-сервер за собой гасить. Порт стенда 5179.

### Задача 1: Граф из проекта — четыре вида ребра

**Файлы:**

**Отдаёт наружу:**
```ts
export type EdgeKind = 'rule' | 'default' | 'broken';
export interface MapEdge {
  readonly from: string;
  readonly to: string;
  readonly kind: EdgeKind;
  /** Подпись у ребра правила; у умолчания пустая. */
  readonly label: string;
}
export interface MapNode {
  readonly id: string;
  readonly title: string;
  readonly description: string;
  readonly isEntry: boolean;
  /** Ничего не выходит: `exit.default === null` и правил нет. */
  readonly isEnding: boolean;
  /** Ни слайдов, ни озвучки — ветка заведена, но пуста. */
  readonly isEmpty: boolean;
}
export function mapGraph(project: Project): { nodes: MapNode[]; edges: MapEdge[] };
```

**Внимание к четвёртому виду.** `broken` — это `goto`, указывающий
на несуществующий id. Ровно ради него отвергнута библиотека: она такие
рёбра теряет молча (ADR-027). Наш код обязан их **находить и отдавать**,
а не пропускать.

**«Конец» — это НЕ ребро.** `exit.default === null` даёт `isEnding`
на узле. У Twine такого состояния нет вовсе; у нас оно законное и частое
(в `conditions.json` два узла из четырёх).

      s.id === 's-deep' ? { ...s, exit: { ...s.exit, default: 's-nonexistent' } } : s,
    ),
  };
}

describe('граф карты', () => {
  it('conditions: четыре узла', () => {
    const { nodes } = mapGraph(conditions);
    expect(nodes.map((n) => n.id)).toEqual(['s-count', 's-next', 's-deep', 's-end']);
  });

  it('умолчание даёт ребро без подписи', () => {
    const { edges } = mapGraph(conditions);
    const e = edges.find((x) => x.from === 's-count')!;
    expect(e).toMatchObject({ to: 's-next', kind: 'default', label: '' });

    const { edges } = mapGraph(conditions);

    expect(e.to).toBe('s-deep');

  it('конец — свойство узла, а не ребро', () => {
    const { nodes, edges } = mapGraph(conditions);

    expect(edges.some((x) => x.from === 's-end')).toBe(false);
  });

  it('ссылка в никуда даёт ребро вида broken, а не пропадает', () => {
    const broken = withBrokenGoto(conditions); // копия в памяти, файл не трогать

    expect(edges.some((x) => x.kind === 'broken')).toBe(true);

  it('стартовая часть помечена', () => {
    const { nodes } = mapGraph(conditions);
    expect(nodes.find((n) => n.isEntry)!.id).toBe('s-count');
  });
});

### Задача 3: Раскладка — чистая функция

**Файлы:**
- Создать: `packages/editor/src/map/layout.ts`
- Создать: `packages/editor/test/map-layout.test.ts`

**Отдаёт наружу:**
```ts
export interface Placed { readonly id: string; readonly x: number; readonly y: number; }
export const NODE_WIDTH = 220;
export const NODE_HEIGHT = 96;
export const NODE_GAP = 25;   // снято с натуры: у Twine шаг 125 при карточке 100
export function layout(nodes: readonly MapNode[], edges: readonly MapEdge[]): Placed[];
```

Слои по достижимости от узла с `isEntry` обходом в ширину; узлы одного
слоя выстраиваются в ряд.

- [ ] **Шаг 1: написать падающий тест**

```ts
describe('раскладка карты', () => {
  it('стартовый узел в первом слое', () => {
    const p = layout(nodes, edges);
    const entry = p.find((n) => n.id === 's-count')!;
    expect(p.every((n) => n.y >= entry.y)).toBe(true);
  });

  it('узлы одного слоя не налезают друг на друга', () => {
    const p = layout(nodes, edges);
    const byRow = new Map<number, Placed[]>();
    for (const n of p) byRow.set(n.y, [...(byRow.get(n.y) ?? []), n]);
    for (const row of byRow.values()) {
      const sorted = [...row].sort((a, b) => a.x - b.x);
      for (let i = 1; i < sorted.length; i += 1) {
        expect(sorted[i]!.x - sorted[i - 1]!.x).toBeGreaterThanOrEqual(NODE_WIDTH + NODE_GAP);
      }
    }
  });

  it('цикл не зацикливает обход', () => {
    // ребро назад: s-end → s-count
    const cyclic = [...edges, { from: 's-end', to: 's-count', kind: 'default', label: '' }];
    expect(() => layout(nodes, cyclic)).not.toThrow();
    expect(layout(nodes, cyclic)).toHaveLength(nodes.length);
  });

  it('недостижимый узел всё равно размещён', () => {
    // иначе автор не увидит того, что надо починить
    const orphan = [...nodes, { id: 's-lost', title: 'Потерянная', description: '',
      isEntry: false, isEnding: true, isEmpty: true }];
    expect(layout(orphan, edges).some((n) => n.id === 's-lost')).toBe(true);
  });
});
```
