# Фундамент и каркас интерфейса редактора — план работ

> **Для агентов:** ОБЯЗАТЕЛЬНЫЙ СУБ-НАВЫК — `superpowers:subagent-driven-development`
> (рекомендуется) или `superpowers:executing-plans`. Шаги помечены
> чекбоксами (`- [ ]`) для отметки хода.

**Цель:** дать редактору общий шрифт, общие размеры и общие детали
интерфейса — и починить раскладку, из-за которой автор физически не может
превратить остановку в развилку.

**Устройство:** три предмета вместе. **Библиотека** в
`packages/editor/src/ui/` даёт то, что переиспользуют. **Навык**
в `.claude/skills/editor-ui/SKILL.md` объясняет, чем пользоваться.
**Охранные тесты** по тексту исходников не дают обойти. Порода охраны уже
работает в проекте — `packages/editor/test/uiTokens.test.ts` держит роли
цвета; новые правила строятся по её образцу.

**Инструменты:** TypeScript, React 19, Vitest (среда **node**, без jsdom
и без testing-library), Playwright. Оформление живёт одной шаблонной
строкой `EDITOR_STYLES` в `packages/editor/src/styles.ts`.

**Спецификация:** [`docs/specs/2026-08-17-editor-ui-system-design.md`](../specs/2026-08-17-editor-ui-system-design.md)

## Общие ограничения

Действуют в КАЖДОЙ задаче.

- **`styles.ts` — ОДНА шаблонная строка, и обратных кавычек в ней нет даже
  внутри комментариев CSS.** Одна такая кавычка обрывает строку и роняет
  весь бандл редактора.
- **Инвариант №5:** рендер у редактора и плеера один. Ни одна задача этого
  плана не трогает отрисовку сцены — только хром редактора.
- **Инвариант №6:** направление зависимостей `editor → player → core`.
  Библиотека `ui/` живёт внутри `editor` и никем снаружи не импортируется.
- **`docs/design/*.md` не меняются** без явного слова владельца. Стало тесно
  в спецификации облика — остановись и спроси.
- **Скриншотные эталоны не перезаписывать не глядя.** Playwright, не найдя
  эталона, пишет `actual` прямо в папку эталонов и роняет тест; перезапуск
  не глядя делает их эталонами МОЛЧА — то есть выключает проверку.
- **Не менять** `DUPLICATE_OFFSET` (40), `SNAP_PX` (8), `STAGE_GAP_X`/
  `STAGE_GAP_Y` (24/16), `MIN_TILE_PX` (24), `MIN_SPAN_SECONDS` (0.25),
  ступени масштаба холста, `IMPORT_SLIDE_SECONDS` (5), `PX_PER_SECOND` (40).
- **Высота нижней зоны — общий ресурс тестов:** её правка роняет чужие
  жестовые e2e через прилипание к направляющим. В этом плане её не трогаем.
- **`pnpm check` в одну команду не укладывается.** Гонять частями:
  `pnpm typecheck`, `pnpm test:unit`, `pnpm build:player`, затем
  `pnpm exec playwright test --shard=1/2` и `--shard=2/2`. **Код возврата
  снимать с каждой команды, не через конвейер.**
- **Два `pnpm check` одновременно дают ложное красное.** Полный прогон —
  только один за раз.
- **Коммитить явным списком путей.** В репозитории может работать
  параллельная сессия; 17.08.2026 чужой `git add -A` втянул посторонний
  журнал в свой коммит.
- **Роль цвета `--ui-surface-canvas` оставить тёмной** — её значение связано
  с `preview.html` инвариантом №5.

## Задача 1: панель метки не имеет права сжиматься в ноль

> ✅ **СДЕЛАНА и ПРИНЯТА 17.08.2026.** Панель развёрнута с 24 px до полных
> 1427. Приёмка — `docs/journal/session-44-journal.md` §4.
>
> ⚠️ **Код тестов ниже НЕ повторять дословно — в нём было три дефекта,**
> и настоящий спек лежит в `e2e/editor-side-column.spec.ts`:
>
> 1. тест 2 щёлкал по гейту и искал плитку перехода, а `TransitionCatalog`
>    вызывается только из `SlideMarkPanel` (`MarkPanel.tsx:1033`) — для
>    гейта рисуется `GatePanel`, плитки в DOM нет вовсе;
> 2. голый `.ed-inspector` неоднозначен: класс носят ДВЕ панели
>    (`Inspector.tsx:91` и `MarkPanel.tsx:186`). Везде нужен
>    `.ed-side > .ed-inspector`;
> 3. `scrollIntoViewIfNeeded` использовать НЕЛЬЗЯ — он прокручивает
>    и вложенный контейнер, то есть добирается до кнопки и через
>    раздавленную панель, оставляя тест зелёным ровно в том состоянии,
>    ради которого он написан. Колонку крутить руками через `scrollTop`.
>
> Число 1576 из этого плана на `two-gates` при 1280×800 не воспроизводится —
> там **1427**. Содержимое панели зависит от ширины окна, видимые 24 px
> не зависят ни от чего.

Самая ценная задача плана: после неё автор может сделать развилку.

**Корень (замерено 17.08.2026).** `.ed-side` — флекс-колонка. Все её дети
объявлены `flex: 0 0 auto`, и это НЕ случайность: комментарий в `styles.ts`
хранит две аварии, купленные делением колонки высотой — у `demo.json`
пятнадцать слайдов выжимали список элементов в ноль, у `branching.json`
щелчок по «Концовка: да» попадал в «Удалить часть». Решение тогда приняли
такое: **колонка прокручивается целиком, подпанели растут по содержимому,
ни одна не сжимает соседей.**

`.ed-inspector` в этот договор не попала. Правила `flex` у неё нет вовсе,
поэтому действует умолчание `0 1 auto` — единственный сжимаемый ребёнок.
Плюс собственные `min-height: 0` и `overflow: auto`. Итог: несжимаемым
нужно 890 px, колонка на ноутбуке даёт 368, всю нехватку вычитают из
панели метки, её вычисленная `height` становится `0px`, а `overflow: auto`
делает это молча.

Собственный комментарий панели говорит: «Своего места в раскладке не
занимает и не назначает: где стоит панель, решает тот, кто её вставляет».
**Поэтому чиним у вставляющего, а не у панели** — договор сохраняем.

**Файлы:**
- Создать: `e2e/editor-side-column.spec.ts`
- Изменить: `packages/editor/src/styles.ts` (правила `.ed-side`, около строки 937)

**Интерфейсы:**
- Использует: существующие классы `.ed-side`, `.ed-inspector`, `.ed-mark-gate`

- [ ] **Шаг 1: написать падающий e2e**

Создать `e2e/editor-side-column.spec.ts`:

```ts
/**
 * Правая колонка: панель выделенной метки обязана быть видна целиком.
 *
 * Проверяем НЕ «нажимается ли» — Playwright перед щелчком сам прокручивает
 * вложенный контейнер и честно нажмёт кнопку внутри 24-пиксельной щели.
 * Проверяем СКОЛЬКО ЕЁ ВИДНО: clientHeight против scrollHeight у самой
 * панели. Замер 17.08.2026 до починки: 24 из 1576, то есть 1.5 %.
 */
import { expect, test, type Page } from '@playwright/test';

test.use({ viewport: { width: 1280, height: 800 } });

async function openEditor(page: Page, fixture: string): Promise<void> {
  await page.goto(`/editor.html?fixture=${fixture}`, { waitUntil: 'load' });
  await page.waitForFunction(() => document.documentElement.dataset['ready'] === '1', null, {
    timeout: 30_000,
  });
}

test('панель выделенной метки не прокручивается внутри себя', async ({ page }) => {
  await openEditor(page, 'two-gates');
  await page.locator('.ed-mark-gate').first().click();

  const size = await page.evaluate(() => {
    const insp = document.querySelector('.ed-inspector');
    if (!insp) throw new Error('панель метки не найдена — тест мерил бы пустоту');
    return { client: insp.clientHeight, scroll: insp.scrollHeight };
  });

  // Положительный контроль: панель действительно с содержимым, а не пустая.
  expect(size.scroll, 'панель пуста — проверять нечего').toBeGreaterThan(200);
  // Собственно проверка: содержимое не обрезано своим же контейнером.
  expect(size.client, `видно ${size.client} из ${size.scroll}`)
    .toBeGreaterThanOrEqual(size.scroll);
});

test('колонка прокручивается целиком, и каталог переходов достижим', async ({ page }) => {
  await openEditor(page, 'two-gates');
  await page.locator('.ed-mark-gate').first().click();

  const tile = page.locator('.ed-transition-tile').first();
  await tile.scrollIntoViewIfNeeded();

  const visible = await page.evaluate(() => {
    const t = document.querySelector('.ed-transition-tile');
    const side = document.querySelector('.ed-side');
    if (!t || !side) throw new Error('плитка перехода или колонка не найдены');
    const a = t.getBoundingClientRect();
    const b = side.getBoundingClientRect();
    return a.top >= b.top - 1 && a.bottom <= b.bottom + 1;
  });

  expect(visible, 'плитка перехода обрезана колонкой даже после прокрутки').toBe(true);
});
```

const SRC = join(process.cwd(), 'packages/editor/src');

/** Все .tsx пакета редактора, кроме самой библиотеки ui/. */
function chromeSources(): { path: string; text: string }[] {
  const out: { path: string; text: string }[] = [];
  const walk = (dir: string): void => {

      }
    }

}

import type { JSX } from 'react';

import { ICON_PATHS, type IconName } from './icons.js';

/**
 * Единственный значок редактора. Размер приходит от кегля строки, в которой
 * значок стоит (1em), а цвет — от currentColor: значок обязан следовать
 * за текстом, рядом с которым он живёт, иначе роли цвета придётся
 * дублировать на каждый случай.
 *
 * aria-hidden по умолчанию: значок сопровождает подпись, а не заменяет её.
 * Значку без подписи вызывающий обязан передать label.
 */
export function Icon({ name, label }: { name: IconName; label?: string }): JSX.Element {
  return (
    <svg
      className="ed-icon"
      viewBox="0 0 24 24"
      fill="none"
      stroke="currentColor"
      strokeWidth={2}
      strokeLinecap="round"
      strokeLinejoin="round"
      aria-hidden={label === undefined}
      aria-label={label}
      role={label === undefined ? undefined : 'img'}
      dangerouslySetInnerHTML={{ __html: ICON_PATHS[name] }}
    />
  );
}
```

import type { ButtonHTMLAttributes, JSX, ReactNode } from 'react';

export type ButtonKind = 'обычная' | 'главная' | 'тихая' | 'значок';

/**
 * Единственная кнопка редактора.
 *
 * Вид задаётся ЗАКРЫТЫМ перечнем, а не строкой класса: строка позволила бы

 * что на подсказки при наведении не смотрят, поэтому причина обязана иметь
 * место в разметке, а не только в title.
 */
export function Button({
  kind = 'обычная',
  reason,
  children,
  ...rest
}: {
  kind?: ButtonKind;
  reason?: string;
  children: ReactNode;
} & ButtonHTMLAttributes<HTMLButtonElement>): JSX.Element {
  return (
    <button
      type="button"
      className={`ed-btn ed-btn-${kind}`}
      title={rest.disabled ? reason : undefined}
      {...rest}
    >
      {children}
    </button>
  );
}
```
