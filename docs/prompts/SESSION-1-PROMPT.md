# Сессия 1 — первый вертикальный срез плеера

Скопируй этот файл целиком в новый чат как первое сообщение.

---

## Что за продукт

Интерактивные объяснения в вебе. Внешне похоже на видео — озвучка, таймлайн,
элементы выезжают и анимируются. Но внутри не видео, а DOM, поэтому зритель
может взаимодействовать.

**Ключевая механика — гейты.** Зритель не может кликать когда угодно. Автор
явно ставит на таймлайне точки, где плеер останавливается и открывает
взаимодействие: выбрать вариант, вписать слово, нажать «дальше». Пока гейт
не пройден, дальше не уехать. Вне гейтов всё на экране — просто картинка.

**Аудио — это часы.** Отдельного таймлайна не существует. Позиция в аудио и
есть время проекта. Гейт — это пауза аудио, без перемотки: звук встаёт, время
замирает, зритель отвечает, звук продолжается с той же секунды.

Первый сегмент рынка: обучение и продуктовые демо с озвучкой.

**Чего в v1 нет:** ветвления сюжета, нескольких сцен, бэкенда, авторизации,
совместного редактирования, AI-генерации, экспорта в MP4.

**Два решения, которые легко нарушить по незнанию:**

- **GSAP брать нельзя.** Его лицензия запрещает использование в инструментах,
  позволяющих создавать анимации визуально. Наш редактор — буквально такой
  инструмент, а инвариант №5 не даёт отделить его от плеера.
- **`<audio>.currentTime` часами быть не может.** В Safari до 27-й версии он
  квантуется по 250 мс.

### Что уже измерено

| Утверждение | Число | Спайк |
|---|---|---|
| часы не расползаются за 10 минут | наклон −0.014 мс/мин | S0b |
| остановка на гейте | перелёт кадра 18.57 мс, позиция 0 мс, недоезд элемента 0 px | S2 |
| пауза не рвёт звук | 0 разрывов, 0 мс скачка позиции | S3 |
| блокировка вне гейта | `elementFromPoint` возвращает `body`, 0 кликов из 6 | S4 |
| паритет рендеров | 0 различающихся пикселей из 921 600 | S7 |
| привязка меток к словам | p95 30 и 90 мс против осциллограммы | S5 |

**Не закрыто:** S6 (fps мерился при посторонней нагрузке, числа выброшены);
всё, что касается iOS Safari — устройства не было, эмуляция не воспроизводит
аудио-политику.

### Готовые куски, которые можно переносить, а не писать заново

- `spikes/lib/audio-clock.mjs` — часы с якорем, симметричными рампами и
  проверкой вменяемости `getOutputTimestamp`. Черновик, но рабочий и измеренный.
- `spikes/lib/render.mjs` — функция рендера сцены и вписывание в контейнер.
- `spikes/s4-gate-lock/` — основа поведенческого теста на блокировку.
- `packages/core/` — схема, валидация, миграции, разрешение `TimeRef`. Готово.

## Инварианты, которые нельзя нарушать

Полный список с пояснениями — в `CLAUDE.md`. Коротко:

1. Аудио — единственный источник времени. Никаких таймеров и счётчиков кадров.
2. Таймлайн ведомый: создаётся в паузе, никогда не играет сам.
3. Вне гейта у сцены `pointer-events: none` — физически, а не «не вешаем обработчик».
4. Гейт останавливает всё сразу, возобновление с той же позиции, перемотки нет.
5. Один рендер на редактор и плеер.
6. `editor → player → core`, обратных импортов нет, `core` не знает про DOM.
7. Изменение схемы = бамп версии + миграция + фикстура + тест.
8. Анимируем только `transform`, `opacity`, `filter`.
9. Плеер — самостоятельный ESM-бандл, открывается в голом HTML.
10. Метки времени привязаны к словам, а не к миллисекундам.

**Два требования, выведенных измерениями, — их легко не заметить:**

- **Ведомый таймлайн обязан покрывать всю дорожку.** anime.js прижимает
  выставленное время к своей длительности. Если анимации кончились на второй
  минуте десятиминутного объяснения, время таймлайна замрёт молча, без ошибки.
- **Рампа усиления обязана быть симметричной.** Затухание без нарастания даёт
  щелчок при каждом возобновлении. Это уже случилось однажды в S3.

## Цель Сессии 1

**Сквозной вертикальный срез плеера.** Без редактора. Проект грузится из
JSON-файла руками.

Плеер должен: загрузить эталонную фикстуру → проиграть аудио → анимировать
элементы синхронно со звуком → остановиться на гейте с выбором ответа →
принять ответ → продолжить с той же позиции.

### Порядок работы

1. `packages/player` — рантайм без фреймворка: часы, ведомый таймлайн, рендер,
   гейты. Рендер переносится из `spikes/lib/render.mjs`, часы — из
   `spikes/lib/audio-clock.mjs`, оба доводятся до продакшен-качества с тестами.
2. `apps/playground` — страница, которая грузит фикстуру и показывает плеер.
3. Сборка плеера в один ESM-бандл + тест, что он открывается в голом HTML.
4. Скриншотные и поведенческие тесты по [ADR-006](../adr/ADR-006-testing.md).
5. Вписать реальные команды сборки и e2e в `CLAUDE.md` (там сейчас `TODO`).

### Критерии приёмки

- [ ] `pnpm check` зелёный и включает типы, юниты, e2e и сборку
- [ ] Плеер грузит `fixtures/projects/two-gates.json` и играет его целиком
- [ ] Элементы анимируются синхронно со звуком; расхождение не измеряется
      отдельно, потому что время присваивается таймлайну каждый кадр
- [ ] На гейте с выбором плеер останавливается; логическая позиция **ровно**
      на времени гейта, элементы в финальном состоянии
- [ ] Верный ответ продолжает воспроизведение с той же секунды; перемотки нет
- [ ] Неверный ответ ведёт себя по `onWrong` из схемы
- [ ] Playwright-тест: вне гейта клики по всем элементам не срабатывают
- [ ] Playwright-тест: пауза и возобновление 20 раз подряд без скачка позиции
- [ ] Плеер собран в самостоятельный ESM-бандл и **проверенно** открывается
      в HTML-файле без сборщика — тестом, а не вручную
- [ ] Тест инвариантов дополнен проверкой, что `player` не импортирует `editor`

### Чего в Сессии 1 не делать

- Редактор и любой UI сложнее playground-страницы
- Бэкенд, базу, авторизацию, деплой
- Ветвление, несколько сцен, множественные аудиодорожки
- Генерацию контента, AI, интеграции, экспорт в MP4
- Красивый дизайн
- Загрузку аудио пользователем и получение таймингов — в фикстуре они уже есть

## Как работать

**Проверь свои skills** в начале сессии и перед каждой новой задачей.

**Ищи в интернете.** Знания устаревают. Версии, лицензии, живость проекта,
изменения браузерных API — проверяй поиском, а не памятью.

**Тестируй в реальном браузере.** Открывай собранное, кликай, смотри консоль.
В Сессии 0 логика паузы была верна и прошла бы любой юнит-тест — дефект сидел
в звуке и нашёлся только измерением сигнала.

**Не мерь производительность на занятой машине.** Один замер в Сессии 0 пришлось
выбросить именно поэтому.

**Планируй до кода.** Plan mode, план на согласование, потом код.

**Спрашивай на развилках.** Остановиться дешевле, чем откатывать.
