# ADR-023: Реестр DOM-рендереров элементов плеера (Player Renderer Registry)

Дата: 2026-08-03
Статус: принято владельцем 03.08.2026.

Продолжает [ADR-003](ADR-003-render.md) (единый рендер сцены)
и [ADR-015](ADR-015-slides-and-segments.md) (слайды и состояний элементов).

## Контекст

Отрисовка элементов сцены в DOM (`packages/player/src/render.ts`) использовала жестко прописанный конструкцией оператор `switch (element.type)`.

При добавлении нового типа элемента сцены (например, `code_block` или `embed`) необходимо было напрямую модифицировать функцию `applyElement` плеера. Это создавало риск появления двойных/параллельных реализаций отрисовки при попытке вынести ветки в редактор или внешние файлы.

## Что отвергнуто

1. **Сохранение старого `switch` в качестве фолбэка.**
   Отвергнуто по Инварианту №5: двойная реализация рендера или молчаливый фолбэк создают скрытый дефект, при котором зарегистрированный рендерер может тихо подменяться устаревшей веткой. Если рендерер для типа элемента не найден, плеер должен падать громко с понятным сообщением.
2. **Дублирование каталогов заготовок в `core` или `editor`.**
   Отвергнуто: единым источником истины для заготовок элементов в редакторе остаётся `packages/editor/src/state/library.ts`. Создание параллельных реестров без реальных вызовов ведет к расхождению дефолтных значений.

## Решение

### Единый реестр DOM-рендереров (`packages/player/src/renderers/registry.ts`)

Отрисовка всех типов элементов (`text`, `image`, `shape` и любых будущих) полностью переведена на `registerElementRenderer` и `getElementRenderer`:

```ts
export type ElementDOMRenderer = (
  node: HTMLElement,
  element: Element,
  state: ElementState,
) => void;

registerElementRenderer('text', (node, element) => {
  node.textContent = element.content;
});
```

В `packages/player/src/render.ts` оператор `switch (element.type)` полностью удален. Отрисовка выполняется исключительно через затребованный рендерер из реестра. При отсутствии зарегистрированного рендерера система выбрасывает ошибку.

## Чем проверяется

- Паритет рендера и скриншотные e2e-тесты Playwright (0 отличающихся пикселей).
- Юнит-тесты `packages/editor/test/renderers.test.ts`.
- Полная проверка `pnpm check`.
