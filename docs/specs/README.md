# Спецификации

Спецификация — подробное описание устройства куска работы, к которому потом
писали код. От [плана](../plans/) отличается тем, что план отвечает «в каком
порядке», а спецификация — «как именно устроено».

Документы исторические: верны на свою дату. Текущее устройство —
[../architecture.md](../architecture.md).
