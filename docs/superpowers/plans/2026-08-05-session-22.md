# Сессия 22: дизайн приходит в продукт. План реализации

> **Исполнителю-агенту:** ОБЯЗАТЕЛЬНЫЙ СУБ-СКИЛЛ — `superpowers:subagent-driven-development`
> либо `superpowers:executing-plans`. Шаги помечены `- [ ]` для отметок.

**Цель:** внести в продукт то, что три дизайнерские сессии произвели в `design/`:
тему сцены, описание части и каталог переходов — одним бампом схемы v8 → v9,
с доказательством, что вид не изменился.

**Подход.** Порядок работ определяется не важностью, а одним доказательством:
если умолчания v9 воспроизводят сегодняшний вид, все **80** скриншотных
эталонов совпадут в ноль пикселей **без единого перезаписанного файла**.
Спайк идёт первым, потому что решает СОДЕРЖИМОЕ перечисления, а перечисление —
это и есть v9. Плеер идёт следом, потому что схема не имеет права обещать
приём, которого плеер не играет.

**Стек:** TypeScript, Zod (`packages/core`), anime.js (`packages/player`),
React 19 (`packages/editor`), Vitest, Playwright.

## Глобальные ограничения

Действуют на КАЖДУЮ задачу, повторять в задачах не требуется.

- **Инвариант №8:** анимируются только `transform`, `opacity`, `filter`.
  Перечень `ANIMATABLE` закрыт и охраняется тестом поимённо
  (`packages/core/test/invariants.test.ts:244`):
  `['x','y','scale','scaleX','scaleY','rotate','opacity','filter']`.
  `clip-path` внести НЕЛЬЗЯ.
- **Инвариант №7:** изменение схемы = бамп версии + функция миграции +
  фикстура + тест. **В этой сессии бамп ровно один: v8 → v9.** Если по ходу
  выясняется, что нужно четвёртое поле — ОСТАНОВИТЬСЯ И СПРОСИТЬ.
- **Инвариант №6:** `editor → player → core`. Обратных импортов нет,
  `core` не знает про DOM и React.
- **Инвариант №5:** один рендер на редактор и плеер.
- **Перезапись скриншотных эталонов ЗАПРЕЩЕНА** на протяжении всей сессии.
  Красное на эталоне означает «умолчание изменило вид» — это и есть проверка.
  Если эталон покраснел, чинить надо код, а не эталон.
- **`MORPH_DURATION_S = 0.6` не меняется по значению.** Число переезжает
  в схему как умолчание, но остаётся 0.6, иначе доказательство «ноль пикселей»
  умирает.
- **Плавность (`ease`) НЕ возвращается.** Отмена запрета 05.08.2026 была
  наполовину: длительность возвращается, `ease` нет. Возврат `ease` = отмена
  решения v2→v3 (`migrations.ts:210`), а не заполнение пробела.
- **`pnpm check` — только ОДИН за раз.** Два одновременных дают ложное красное:
  оба поднимают дев-сервер на 5179 и оба пишут в
  `apps/playground/public/bundle/player.js`. Перед полным прогоном порт
  зачищать явно: `Get-NetTCPConnection -LocalPort 5179`.
- **Код возврата конвейера — не код команды.** `pnpm check 2>&1 | tail -30`
  возвращает код `tail`. Зелень докладывать только увидев числа в выводе.
- **Позиционирование не просачивается в код.** Никаких `lesson`, `section`,
  «урок», «ученик», «раздел». Пиши сегмент, зритель, объяснение.
- **Никаких новых файлов, которых план не называет.**

## Задача 1. Спайк S12: «Штора» и «Круг» — ВЫПОЛНЕНО 05.08.2026

> **Результат: оба приёма ПРОШЛИ.** p5 58.8 («Штора») и 59.2 («Круг») при

>

> В прогон добавлен ПРОГРЕВОЧНЫЙ проход, а проверка инварианта №8 перенесена

здесь значило бы сломать проверку имени токена, причём молча: `undefined in {}`
не бросает, а даёт `false`, и ЛЮБАЯ ссылка на токен стала бы «нераспознанной».

```ts
/**
 * Ссылка на роль темы: `var(--scene-accent, #4c8dff)`.
 *
 * Запасное значение ОБЯЗАТЕЛЬНО, и это не педантизм. Измерено S11:
 * неизвестный токен проваливается МОЛЧА — браузер отбрасывает объявление
 * целиком, автор видит чёрный текст, в консоли ни ошибки, ни предупреждения.
 * Ссылка без запаса — заряженное ружьё, поэтому ссылкой она не считается.
 *
 * Имя проверяется по ЗАКРЫТОМУ списку ролей: `var(--scene-выдумка, ...)`
 * покажется автору как обычная ссылка, а покрасит запасным цветом — то есть
 * соврёт про то, что тема на него влияет.
 */
const TOKEN_REF = /^var\(\s*(--scene-[a-z-]+)\s*,\s*([^)]+?)\s*\)$/;

function tryToken(raw: string | number): { token: string; fallback: string } | undefined {
  const match = TOKEN_REF.exec(String(raw).trim());
  if (!match) return undefined;
  const [, token, fallback] = match;
  return token! in ThemeSchema.shape ? { token: token!, fallback: fallback! } : undefined;
}
```
