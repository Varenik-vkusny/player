# Сессия 51 — форма органов и понятная развилка

> **Для агентов:** ОБЯЗАТЕЛЬНЫЙ СУБ-НАВЫК — `superpowers:subagent-driven-development`.

**Требование владельца, 18.08.2026 ночью, близко к тексту:** к утру
не остаётся ничего от дефолтного html; виден полноценно новый облик;
автор точно понимает, что и откуда делать; и **библиотека компонентов
на будущее закрыта здесь**.

**Две половины, и вторая важнее первой.**

---

## ⬛ ПОЧЕМУ ВТОРАЯ ПОЛОВИНА ВАЖНЕЕ

18.08.2026 владелец — **создатель продукта** — нажал «разделить здесь»
и не понял, что произошло.

Воспроизведено приёмщиком. Происходит вот что: глава режется надвое
и связывается правилом **«иначе → продолжение»**. Это ШОВ, а не развилка.

Чтобы получился выбор, нужно ещё **четыре действия в четырёх местах**:

| шаг | где живёт |
|---|---|
| поставить остановку | соседняя кнопка транспорта |
| сменить её вид на «Выбор варианта» | панель метки, справа внизу |
| вписать варианты | там же |
| создать главу под каждый ответ | «Добавить главу», правая колонка |
| развести ответы по главам | секция «Правила выхода» |

Ни одно не следует из слова «разделить», и ни одно место не говорит,
что делать дальше.

⚠️ **МОДЕЛЬ МЕНЯТЬ НЕЛЬЗЯ.** Метка — стык глав (`product.md`, **[Р]**);
остановка записывает ответ и никуда не перекидывает; куда идти — решает
выход главы (ADR-015). Чинится **показ**, а не устройство.

## Половина А: ни одного дефолтного органа

### Задача А1: ПЕРЕПИСЬ, и только потом правка

Правило навыка, дважды окупившееся: «84 кнопки» оказались 42 копиями
одной и 42 разными органами.

Известно на 18.08.2026 — **перемерить каждое, расхождение это находка**:

| орган | сколько |
|---|---|
| `select` | 11 в исходниках, 5 отрисованных |
| `checkbox` | 3 |
| `radio` | 1 |
| `number` | 1 |
| `file` | 3 |
| `range` | 1 |
| `textarea` | 3 |
| прокручиваемых узлов | 10 — **полосы уже покрашены** |
| органов вне общей кнопки | **42 в 36 классах** (перепись Сессии 45) |

### Задача А2: библиотека закрывается

**Это и есть «компоненты для будущего».** В `ui/` уже есть `Button`,
`Icon`, `Section`, `AlignIcon`, `ScrollStrip`. Добавить недостающее,
чтобы **каждый род органа имел свой компонент**:

- [ ] `Field` — подпись плюс орган плюс место под причину;
- [ ] `Select` — закрытое состояние своё, **список родной**
      (решение приёмщика 18.08.2026: в тёмной зоне списков нет вовсе,
      а родной даёт бесплатно клавиатуру, автозакрытие и чтение с экрана);
- [ ] `Checkbox`, `Radio` — своя отрисовка поверх родного input,
      **поведение родное**;
- [ ] `NumberField` — без браузерных стрелок, со своими;
- [ ] `FileField` — кнопка вместо родной надписи «Выберите файл»;
- [ ] `Slider` — для `range`;
- [ ] `TextArea`.

⚠️ **Поведение не меняется ни у одного:** клавиатура, `aria`, чтение
с экрана, фокус. Замена облика — не замена органа.

### Задача А3: охрана, которая не даст вернуться

- [ ] расширить `uiChrome.test.ts`: вне `ui/` не встречается ни одного
      сырого `select`, `input`, `textarea`;
- [ ] **доказать возвращённой бедой**: вернуть один сырой орган, увидеть
      красное, вернуть, увидеть зелёное, грепом проверить.

### Задача А4: 42 органа получают общий вид

Перепись Сессии 45 назвала их: несущие состояние, виджеты дорожки, свои
размеры, своя семантика. **Опознаваемость не снимать** — привести к общим
поверхностям, скруглениям, отступам и состояниям, оставив различия там,
где они несут смысл.

## Общие ограничения

- **Модель не менять**: решения `[Р]`, инварианты, ADR-015.
- **Раскладку не переставлять** — утверждена как узнаваемая.
- **Отрисовку сцены не трогать** — инвариант №5.
- **Поле вокруг листа остаётся тёмным** — измеренный отказ, причина
  записана в `styles.ts` рядом с ролью.
- `styles.ts` — одна шаблонная строка, обратных кавычек внутри нет.
- **Не менять** `docs/design/*.md`, `docs/product.md`, ширину каталога 350.
- Эталоны **принимает приёмщик**, в конце и разом.
- **Изменяющие git-команды запрещены**, включая `git checkout --`.

## Как делить работу

`styles.ts` правит **только сама сессия**, последовательно. Исполнителям
на Sonnet — замеры, перепись, снимки на трёх размерах, проверка фикстур,
и **задачи половины Б** (они трогают разные панели).

## Доказательства

Кроме падающего теста и слома — **снимки на трёх размерах окна для глаз
приёмщика** и **список различий с макетом** на каждом шаге: макет —
нижняя граница, а не образец для копирования чисел.
