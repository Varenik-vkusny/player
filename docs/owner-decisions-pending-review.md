# Решения, принятые ЗА владельца — ждут его пересмотра

Заведён 17.08.2026 ночью. Владелец разрешил принимать решения самому,
чтобы работа шла, пока он спит, и просил сделать всё «нормально
поддерживаемым».

**Поддерживаемо — значит обратимо.** Поэтому каждое решение, принятое
в его отсутствие, записано здесь: что решено, почему, **и как отменить**.
Ни одно из них не спрятано в коде и не подано как «так и было».

## Правила, которые я себе поставил на ночь

1. **Решения [Р] из `docs/product.md` не переоткрываю** — вообще, ни при
   каких обстоятельствах. Они помечены как окончательные, и разрешение
   «решай сам» их не отменяет.
2. **Инварианты не нарушаю.** Требуется нарушить — задача откладывается
   до утра, а не «решается».
3. **`docs/design/*.md` не меняю** — там записан облик, и он его.
4. **Всё, что меняет ОБЛИК заметно**, делаю обратимым одной строкой
   и записываю сюда.
5. Если развилка не имеет очевидно правильной стороны и цена ошибки
   больше часа работы — **откладываю до утра**, а не угадываю.

## Решения

### 1. База текста осталась 14px, а не уехала на 13

| | |
|---|---|
| **Когда** | 17.08.2026, приёмка Задачи 2 |
| **Что решено** | `--ui-type-m: 14px` |
| **Почему** | Таблица плана «13 и 14 в m» в применении к базе хрома увела её 14 → 13, то есть уменьшила ВЕСЬ текст редактора. Программа затеяна ради читаемости; уменьшать базу в ней — движение назад. Цена возврата измерена: содержимое правой колонки 2212 → 2252 px, **плюс 1.8 %** |
| **Как отменить** | Одна строка в `styles.ts`: `--ui-type-m: 13px` |

### 2. Гарнитура — системный стек, а не выбранная вами

| | |
|---|---|
| **Что решено** | `--ui-font: system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif` |
| **Почему** | Интерфейс целиком на русском; системный стек даёт кириллицу без файла шрифта, лицензии, загрузки и ADR. Выбирать гарнитуру по названию вслепую хуже, чем глядя на экран |
| **Как отменить** | Одна строка в блоке ролей `styles.ts`. Своя гарнитура потребует ADR и файлов |

### 3. Набор значков — Lucide, контуры вложены, пакет не ставится

| | |
|---|---|
| **Что решено** | ADR-034 |
| **Почему** | Вы выбрали «готовый бесплатный набор». Lucide проверен по первоисточнику: ISC, часть MIT; запрета на визуальные редакторы нет (в отличие от GSAP). Вкладывание контуров вместо пакета — чтобы не заводить зависимость в сборке |
| **Как отменить** | Заменить контуры в `ui/icons.ts`; интерфейс `Icon` не изменится |

### 4. Эталоны хрома сняты только на Windows

| | |
|---|---|
| **Что решено** | Суффикс `-win32`, нулевой допуск пер-вызовом |
| **Почему** | Все 120 прежних эталонов уже win32, а CI на ubuntu красный с 02.08.2026 и пройти не может в принципе. Хуже не стало; лучше станет, когда починят CI (записано в долги) |
| **Как отменить** | Снять эталоны на Linux и убрать привязку к платформе |

### 5. Сорок два «органа управления» не сведены к видам кнопки

| | |
|---|---|
| **Что решено** | Свели только 42 копии одного класса; 42 разных органа в 36 обличьях оставлены как есть |
| **Почему** | Ваше же направление: устройство снимаем с натуры, а не изобретаем. Назвать облик 42 органов без натуры — это изобретение. Втиснуть их в четыре вида можно только сняв опознаваемость |
| **Как отменить** | Ничего отменять не нужно: это отложено, а не сделано |

### 6. Складной становится сама панель, а не обёртка вокруг неё

| | |
|---|---|
| **Что решено** | `ui/Section` даёт заголовок со стрелкой; панели зовут его вместо своего `<h2>` |
| **Почему** | Семь панелей уже рисуют свой `<h2>`. Обёртка снаружи дала бы два заголовка и заставила бы два компонента договариваться о тексте — тот самый разнобой, ради конца которого заводится библиотека |
| **Как отменить** | Вернуть `<h2>` в панель и снять складывание |

### 7. Складными сделаны только ЭЛЕМЕНТЫ, СЛАЙДЫ, ГЛАВЫ

| | |
|---|---|
| **Почему** | Панель метки складной НЕ сделана намеренно: она и так появляется только при выделении, и прятать её значило бы вернуть беду, которую чинили Задачей 1. По умолчанию все три раскрыты — закрывать молча значит спрятать от автора то, что он видел вчера |
| **Как отменить** | Снять или добавить вызовы `Section` в панелях |

### 8. CI не чинится в этой программе

| | |
|---|---|
| **Почему** | Красный с 02.08.2026 и не может пройти: 125 эталонов привязаны к win32, проверка идёт на ubuntu. Это не предмет дизайна, и лезть в него посреди программы значило бы менять предмет молча. Записано в `debt.md` отдельным пунктом |
| **Как отменить** | Отдельная задача: снять эталоны на Linux либо развести эталоны по платформам |

### 9. Стрелка складывания ушла к ПРАВОМУ краю заголовка

| | |
|---|---|
| **Когда** | 17.08.2026 ночью, приёмка Задачи 7 |
| **Что решено** | `.ed-section-name { order: -1 }` — подпись первой, стрелка справа |
| **Почему** | Замерено: стрелка в начале строки выталкивала заголовок на **17 px** внутрь, и в узкой колонке появлялась ТРЕТЬЯ левая кромка — строки списка 1035, чип слайда 1042, заголовок 1052. До появления стрелки заголовок стоял на 1035 вместе со строками. **Это возврат прежней кромки, а не новый приём** — потому и решил сам, а не отложил |
| **Как отменить** | Убрать `order: -1` и переснять один эталон |

### 10. Навык `editor-ui` положен в репозиторий

| | |
|---|---|
| **Что решено** | `.claude/skills/editor-ui/SKILL.md` коммитится вместе с кодом |
| **Почему** | Он описывает, чем пользоваться в ЭТОМ проекте, и обязан ехать вместе с ним: иначе следующая сессия получит библиотеку без инструкции. Ничего личного или машинно-зависимого в каталоге нет — там один файл |
| **Как отменить** | Удалить каталог и добавить `.claude/` в `.gitignore` |

## ⬛ ДВА ВОПРОСА ВЛАДЕЛЬЦУ — с числами, ждут утра

Оба про облик, оба независимы: **второй нельзя закрыть первым.**

### Вопрос 1. Сколько экрана отдать холсту против каталога

Умолчание ширины каталога — **350 px**, и оно из утверждённого каркаса
(`design/tokens.css:43`). Автор может менять её сам (ручка, 260…560,
плюс сворачивание в ноль), но открывает редактор он на умолчании.

| окно и каталог | холсту | доля | «Вписать» |
|---|---|---|---|
| 1280, открыт | 586 | **45.8 %** | 28 % |
| 1280, свёрнут | 942 | 73.6 % | 33 % |
| 1900, открыт | 1206 | 63.5 % | 33 % |
| 1900, свёрнут | 1562 | 82.2 % | 33 % |

На ноутбуке каталог забирает больше половины ширины. Уменьшение
умолчания до 260 (нижняя граница, уже узаконенная в коде) дало бы холсту
676 вместо 586.

**Почему не решаю сам:** это каркас, снятый с натуры, и вопрос «что автор
видит, открыв редактор». Плюс ширина холста двигает «Вписать», а масштаб
сцены — общий ресурс жестовых тестов.

**Проверенное отдельно:** делать каталог «по содержимому» НЕЛЬЗЯ — он стал
бы шире. Истинная нужда панелей: Тема 789, Шаблоны 666, Фигуры 486. Три
панели из шести уже теснее своей нужды.

### Вопрос 2. Полоса свойств не влезает в ноутбучное окно НИКОГДА

Содержимое полосы — **1276 px, и от окна не зависит**: она не сжимается,
а прокручивается. Порог помещаемости:

| каталог | помещается с окна | органов целиком за краем при 1280 |
|---|---|---|
| свёрнут | **1700** | 8 из 14 |
| открыт | **2000** | **14 из 14 — все** |

**Ширина каталога это не решает** — при свёрнутом каталоге порог всё равно
1700, то есть выше любого ноутбука.

Честная оговорка: полоса стала переполняться **сильнее на 191 px** после
починки 18.08.2026, и это прямая цена честности. Раскладывается без
остатка: **+156** — тринадцать кнопок получили свои 28 px вместо 16
(по ним нельзя было попасть), **+35** — список шрифтов перестал резать
собственное значение. Прежнее «при 1440 со свёрнутым каталогом помещается»
было куплено кнопками шириной 17 px.

**Три возможных ответа, и все про облик:**

1. убрать часть органов со строки (например, за существующую дверь «Ещё…»);
2. разложить в две строки — но высота полосы **постоянна** и это куплено
   дефектом двойного щелчка Сессии 29;
3. растянуть полосу во всю ширину окна — **отступление от каркаса**:
   проверено, в `design/index.html` полоса стоит внутри колонки холста,
   а не над всем окном.

**Почему не решаю сам:** любой из трёх меняет то, что автор видит
постоянно, и все три спорят с утверждённым каркасом.
