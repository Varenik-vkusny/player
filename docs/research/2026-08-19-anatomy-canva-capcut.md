## Как снято

| прибор | для чего |
|---|---|
| расширение Claude, живой Chrome | глаза: снимки, состояние страницы |
| `getBoundingClientRect` в самой странице | числа |

**Числа сняты замером в живой странице, не глазами по картинке.** Это не
придирка: снимок расширения приходит НЕ в CSS-пикселях — окно 1440×900
отдаёт снимок 1568×761. Любое число, снятое линейкой по картинке, было бы
завышено примерно на 9 %.

Окно при всех замерах: **1440 × 900**. Канва — рабочий редактор презентации
владельца (`canva.com/design/DAHSWMZX9hc/edit`), не витрина и не маркетинговая
страница.

Всё, что помечено **[перепроверить]**, замерено на боксе, который может
оказаться обёрткой, а не самим текстом. Такое в отчёт как факт не идёт.

## Б) Анатомия области каталога у Канвы

Это та часть, ради которой затевался Шаг 0: по ней собирается Часть 1.

### Левая узкая рейка

| что | число |
|---|---|
| ширина рейки | **72 px** |
| размер пункта | **72 × 72 px** |
| шаг пунктов по вертикали | **72 px** (зазора между пунктами нет) |
| первый пункт начинается | y = 65 |
| кегль подписи | **10 px** |
| подпись под значком | **есть, всегда** |
| раскладка пункта | значок сверху, подпись под ним, по центру |

Пункты сверху вниз: Шаблоны, Элементы, Текст, Бренд, Загрузки, Инструменты,
Проекты, Приложения, затем отбивка и Code To Image (стороннее приложение).

**Выбранный пункт показан цветом значка и подписи** — они становятся
фиолетовыми, фона-плашки под выбранным пунктом нет.

Существенное для нас: **подпись под значком есть у каждого пункта и она
не прячется.** Рейка без подписей у Канвы не встречается ни в одном
состоянии — при ширине 72 px подпись в 10 px помещается целиком.

### Раскрытая панель

| что | число |
|---|---|
| левый край | x = 72 (впритык к рейке) |
| **ширина панели** | **361 px** |
| высота | 855 (во всю высоту под шапкой) |
| фон | сплошной белый `rgb(255,255,255)` |
| верхний край | y = 57 — это и есть высота шапки приложения |
| поле содержимого слева | 16 px (содержимое начинается с x = 88) |
| **ширина колонки содержимого** | **313 px** |

Наш каталог сегодня — **350 px**. Канвовские 361 отличаются на 11 px,
то есть ширина у нас уже почти натурная и трогать её не нужно.

### Сетка плиток — ДВЕ РАЗНЫЕ, и это главное открытие шага

У Канвы сетка плиток не одна. Их две, и различаются они не оформлением,
а тем, **что плитка показывает**.

**Каталог шаблонов** (пункт «Шаблоны»):

| что | число |
|---|---|
| колонок | **2** |
| размер плитки | **152.5 × 85.8 px** |
| соотношение сторон | **1.777 — ровно 16:9**, то есть форма самого слайда |
| зазор между колонками | **8 px** (шаг 160.5) |
| зазор между рядами | **8 px** (шаг 93.8) |
| что нарисовано внутри | **уменьшенный снимок самого шаблона** |
| подпись | **НЕТ ВООБЩЕ** |

Сходится: 152.5 × 2 + 8 = **313** — ровно ширина колонки содержимого.

**Каталог элементов** (пункт «Элементы», раздел «Просмотр категорий»):

| что | число |
|---|---|
| колонок | **3** |
| размер рисунка плитки | **99 × 99 px**, соотношение **1:1** |
| зазор | **8 px** (шаг 107) |
| полная высота плитки с подписью | 119 px (то есть на подпись ~20 px) |
| кегль подписи | **10 px** |
| где подпись | **под рисунком**, по центру |

Сходится: 99 × 3 + 8 × 2 = **313** — та же колонка содержимого.

**Вывод, который стоит всего шага.** У Канвы **одна ширина колонки (313) и
один зазор (8)**, а число колонок выводится из формы содержимого:

- показываешь **раскладку слайда** — плитка 16:9, **2 колонки, подписи нет**,
  потому что картинка раскладки сама себя называет;
- показываешь **вид объекта** — плитка 1:1, **3 колонки, подпись под ней**,
  потому что по иконке не догадаться, что это «Фигуры», а не «Формы».

Это прямо отвечает на вопрос Части 1: наши шаблоны сцены — это раскладки,
значит им 16:9 и две колонки; наши элементы (текст, фигура) — это объекты,
значит им 1:1, три колонки и подпись.

### Шапка панели

Над сеткой у каждой панели своя шапка. У «Шаблонов» это строка поиска
с подсказкой «Презентация: поиск шаблонов», у «Элементов» — поле запроса
«Опишите свой идеальный…». Кнопки закрытия в самой шапке нет: панель
сворачивается отдельным язычком `‹` на её правой границе (виден на снимке
на середине высоты, x ≈ 360).

Заголовки разделов внутри панели идут парой «название слева — ссылка
справа»: «Недавно использованные … Показать все», «Больше шаблонов для
вас … Просмотреть все».

| что | число |
|---|---|
| ссылка «Просмотреть все» | кегль **12 px**, насыщенность **600**, цвет `rgba(15,16,21,0.85)` |
| заголовок раздела | **[перепроверить]** — замер дал 10 px/400 на боксе высотой 40, похоже на обёртку |

### Чего у Канвы в каталоге НЕТ

Пустого состояния в каталоге поймать не удалось: все разделы у живого
пользователя непустые. **Это не «пустого состояния нет», а «не замерено»** —
разница существенная, и выдавать одно за другое нельзя.

## Каркас `design/shell.css` — второй, независимый канал

Найден по указанию приёмщика **после** того, как числа выше были сняты
с живой Канвы. Это важно: каналы независимы, и потому их совпадение
что-то значит.

`design/shell.css` (05.08.2026, 119 правил) + `design/tokens.css`
(68 переменных). Открывается двойным щелчком через `design/index.html`.

**Совпало с натурой дословно:**

| часть каркаса | что в нём | что я замерила у Канвы |
|---|---|---|
| `.gallery` | `grid-template-columns: repeat(2, 1fr)` | **2 колонки** ✓ |
| `.gallery__cell` | `aspect-ratio: 16 / 9` | **16:9** ✓ |
| `.catalog` | ширина 350, в комментарии «из документации Canva» | замер дал **361** — расхождение 11 px |
| `.catalog__body` | «единственная полоса прокрутки на панель» | у Канвы прокрутка одна ✓ |
| `.rail__item` | `display: grid`, значок над подписью, `gap: 2px` | значок над подписью ✓ |
| `.rail__item[aria-pressed="true"]` | выбранное — фоном | у Канвы выбранное — **цветом, без фона** ✗ |

Совпадение по сетке — **не совпадение вкусов, а сходимость двух замеров**:
каркас писался по документации Канвы по раскладке, я мерила живой продукт.
Два канала дали 2 колонки и 16:9 порознь. Дальше это можно не обсуждать.

**Что в каркасе брать нельзя.** `.rail__glyph { font-size: 18px }` — рейка
каркаса рисует значки **символами из шрифта**, тем же способом, что наш
нынешний `chrome/catalog.ts` (глифы `▦ ◇ T ◐ ✦ ↑`). Навык `editor-ui`
это прямо запрещает, ADR-034 объясняет чем: на машине без глифа остаётся
пустой прямоугольник, и ни ошибки, ни предупреждения не будет. Каркас
здесь не образец, а тот же дефект, что у нас.

**Итог по каркасу: он годится как источник ИМЁН и СЕТКИ, но не как
источник значков.** Заводя `Panel`/`Tile`/`TileGrid`, беру из него
членение (`__head` / `__body`, галерея исключением из «колонкой»)
и числа сетки, а значки делаю контурами через `Icon`.
